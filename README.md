# Edu-center API

API для автоматизації управління освітнім центром. Проєкт побудований на Django та Docker для зручного розгортання.

## Основні можливості
* **Управління користувачами**: Адміністратори та викладачі.
* **Облік студентів**: База даних студентів та їхніх батьків.
* **Навчальний процес**: Філії, предмети, групи та уроки.
* **Підписки**: Управління тарифними планами та підписками студентів.
* **Аналітика**: Вбудована документація API через Swagger.

## Технології
* **Backend**: Django 6.0.4, Django Rest Framework
* **Документація**: drf-spectacular (Swagger)
* **Контейнеризація**: Docker
* **База даних**: SQLite (для розробки)

## Як запустити проєкт

### Вимоги
* Встановлений [Docker Desktop](https://www.docker.com/products/docker-desktop/).

### Кроки для запуску
1. Клонуйте репозиторій (або перейдіть у папку проєкту):
   ```bash
   cd Edu-center
2. Запустіть проєкт за допомогою Docker:

    Bash
    docker-compose up --build

3. Після успішного запуску перейдіть у браузері за адресою:
    http://127.0.0.1:8000/api/v1/docs/


## Структура проєкту
api/ — серіалізатори та налаштування API.

config/ — глобальні налаштування Django (settings, urls).

students/, branches/, lessons/, subscriptions/ — основні модулі (додатки) системи.
